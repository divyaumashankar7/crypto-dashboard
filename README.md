# 🚀 Crypto Market Dashboard

An interactive cryptocurrency analytics dashboard built with React.

## 🌐 Live Demo
https://divyaumashankar7.github.io/crypto-dashboard

## ✨ Features

- 🔎 Search cryptocurrencies
- 📊 Sort by price & 24h change
- 📈 Interactive price charts
- 🌙 Dark / Light mode toggle
- 🪙 Coin logos & ranking
- ⚡ Real-time data via CoinGecko API

## 🛠 Tech Stack

- React + Vite
- JavaScript
- Chart.js
- CSS
- CoinGecko API

## 📦 Deployment

Deployed using GitHub Pages.
